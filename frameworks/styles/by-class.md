# Meta-build guides — class index

**Class is a view; styles are canonical.** Players search by class ("I want to play a Witch"), but shared
infrastructure lives at the style layer — so this index is thin rows pointing into style files, and one
build can appear under several classes. Attributions from the [minions roster](minions.md); ◐ = ascendancy
per community survey, not independently verified.

| Class / Ascendancy | Builds (all detailed in [`minions.md`](minions.md)) |
|---|---|
| **Witch / Necromancer** | Poison SRS · pRAW · Holy Relic (classic) · Block SRS (maintainer play-proven) · zoomancer · skeleton mages · spectre army · turtle spectres · Popcorn SRS · Soulwrest phantasms · Chains of Command · SRS/Absolution leveling trunk |
| **Witch / Elementalist** | Golem buff-shell (golems scale the player) |
| **Templar / Guardian** | Dominating Blow / Absolution sentinels ◐ |
| **Duelist / Gladiator** | Holy Relic variant (Determined Survivor lucky-block) ◐ |

As more styles land (totems, melee, …), their class rows merge into this same index.
